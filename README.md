# 🌟 Random Quote Generator

## 📌 Project Overview

The Random Quote Generator is a simple and interactive web application developed using HTML, CSS, and JavaScript. It generates random quotes to inspire and motivate users with just a click.

This project was created as part of my web development learning journey during my **CodeAlpha Internship**.

## 🎯 Features

* 📝 Generates random quotes.
* 🎨 Simple and attractive user interface.
* ⚡ Interactive functionality using JavaScript.
* 🖱️ Easy-to-use interface.
* 📱 Clean and responsive design.

## 🛠️ Technologies Used

* **HTML5** – Structures the webpage.
* **CSS3** – Styles the application.
* **JavaScript** – Generates random quotes dynamically.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Open `index.html` in your web browser.
5. Click the button to generate a random quote.
